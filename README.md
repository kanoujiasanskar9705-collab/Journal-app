# Journal Application Backend

## Description
This project is a RESTful backend for a journal application built using Java and Spring Boot. It allows users to create, read, update, and delete journal entries efficiently.

## Features
- CRUD operations for journal entries
- REST API using Spring Boot
- MongoDB integration
- Structured backend architecture

## Technologies Used
- Java
- Spring Boot
- MongoDB

## How to Run
1. Clone the repository
2. Open in IDE (IntelliJ / Eclipse)
3. Configure MongoDB connection
4. Run the Spring Boot application

## API Endpoints
- GET /journals → Get all entries
- POST /journals → Create entry
- PUT /journals/{id} → Update entry
- DELETE /journals/{id} → Delete entry
